# WeFolio 재설계 PRD

가족의 자산 포트폴리오를 완성해 나가는 **가계부 & 자산 관리 서비스** (We + Portfolio)를
처음부터 다시 빌드하기 위한 요구사항 문서 모음입니다.

## 왜 다시 만드는가

기존 구현은 자산 관리에서 **현금 잔고와 투자 종목이 뒤섞여** 있었고,
거래 기반 추적(`HoldingTransaction`)과 월별 수동 스냅샷(`HoldingValueSnapshot`)이
**이중으로 분리**되어 정합성 보증이 어려웠다. 결과적으로 "투자 현황·수익 상태"를
한눈에 보여주는 인사이트 구조가 부족했다.

이번 재설계의 한 줄 목표:

> **현금 잔고와 투자 종목을 명확히 분리하고, 월별 스냅샷 하나만으로
> 투자 수익과 자산 증가의 원인(저축 vs 투자수익)을 보여준다.**

## 핵심 원칙

1. **2분류**: 모든 자산은 _현금 잔고(cash)_ 또는 _투자 종목(holding)_ 중 하나다.
2. **단일 진실원천(SSOT)**: 월별 스냅샷이 유일한 사실. 거래 기록 테이블을 두지 않는다.
3. **상태 직접 수정**: 매월 전월값을 복사하고, 바뀐 값만 직접 고친다. (매매 추적 없음)
4. **간결성 우선**: 계산 불가능한 지표는 만들지 않는다. 모든 인사이트는 스냅샷 필드만으로 산출된다.
