# Manual Verification Checklist

이 문서는 자동 테스트로 잡기 어려운 주요 화면의 기본 로딩, 빈 상태, 주요 액션을 수동으로 확인하기 위한 체크리스트입니다.

## 공통

- [ ] 앱 레이아웃과 LNB가 데스크톱/모바일 폭에서 겹치지 않는다.
- [ ] 월/기간 선택 컨트롤이 선택한 값으로 화면 데이터를 다시 로드한다.
- [ ] 데이터가 없을 때 빈 상태가 깨진 표나 차트 대신 표시된다.
- [ ] API 오류 발생 시 화면 전체가 무한 로딩에 빠지지 않는다.

## 월간 가계부 허브 (`/budget/monthly`)

- [ ] 월 진입 시 잔액 KPI가 상단 핵심 지표로 보이고 총수입, 총지출 카드가 함께 로드된다.
- [ ] `요약`/`거래 목록` 탭 전환 시 월 선택 상태가 유지되고 URL query가 자연스럽게 갱신된다.
- [ ] 금액이 길어져도 KPI 카드 안에서 텍스트가 겹치거나 잘리지 않는다.
- [ ] 수입/지출 비교 카드와 카테고리 분석 카드가 데스크톱/모바일 폭에서 자연스럽게 배치된다.
- [ ] 거래가 없는 월에서 KPI는 0원으로 표시되고 수입/지출 차트는 빈 상태로 표시된다.
- [ ] 선택한 수입/지출 유형에 카테고리 데이터가 없으면 카테고리 차트 대신 빈 상태가 표시된다.
- [ ] 카테고리 지출/수입 전환, 대분류 선택, 소분류 선택 후 상세 패널이 선택 항목에 맞게 표시된다.
- [ ] 요약 탭에서 최근 거래가 과밀하지 않게 표시되고 거래가 없을 때 빈 상태가 표시된다.
- [ ] 월 이동 후 KPI, 수입/지출 비교, 카테고리 분석이 같은 월 기준으로 갱신된다.
- [ ] `거래 추가`를 누르면 페이지 이동 없이 입력 패널/시트가 열리고 닫힌다.
- [ ] 입력 패널에서 저장 후 요약 KPI와 거래 목록이 갱신된다.
- [ ] 다크 모드와 작은 화면에서 버튼, 탭, 입력 패널, KPI 금액, 차트 중앙 라벨, 카테고리 목록, 상세 패널 텍스트가 겹치지 않는다.

## 월별 상세 (`/budget/monthly?view=detail`)

- [ ] 월별 거래 목록이 날짜/카테고리/금액/사용자/결제수단과 함께 표시된다.
- [ ] 수입/지출 필터와 카테고리 필터가 목록에 반영된다.
- [ ] 표 하단 인라인 입력에서 거래 저장 후 목록과 요약 데이터가 갱신된다.
- [ ] 삭제 액션 후 목록과 요약 데이터가 어긋나지 않는다.
- [ ] 거래가 없는 월에서 빈 목록 상태가 표시된다.
- [ ] `/budget/monthly/detail?year=YYYY&month=M` 직접 진입 시 새 상세 탭 URL로 연결된다.

## 거래 입력 (`/budget/monthly?input=open`)

- [ ] 사용자, 유형, 날짜, 메모, 카테고리, 결제수단, 금액 순서로 입력이 진행된다.
- [ ] 선택 입력 단계는 건너뛸 수 있고 필수 입력이 없으면 저장되지 않는다.
- [ ] 저장 성공 후 직전 저장 목록에 거래가 추가되고 입력 폼이 초기화된다.
- [ ] 저장된 거래 수정 후 목록의 금액/카테고리/메모가 갱신된다.
- [ ] 저장된 거래 삭제 후 목록에서 제거되고 실패 시 오류 상태가 표시된다.
- [ ] localStorage에 저장된 사용자/유형/현재 월 날짜가 다음 진입 시 기본값으로 반영된다.
- [ ] `/budget/monthly/input?year=YYYY&month=M` 직접 진입 시 입력 패널이 열린 새 허브 URL로 연결된다.

## 자산 월별 현황 (`/asset/monthly`)

- [ ] 월 진입 시 총자산, 전월 대비, 보유 자산 목록이 표시된다.
- [ ] 리스크 분포와 월별 요약 카드가 같은 월 기준으로 표시된다.
- [ ] 스냅샷이 없는 월에서 빈 상태가 표시된다.
- [ ] 월 이동 시 전월 대비 금액과 보유 목록 delta가 갱신된다.
- [ ] `이번 달 자산 입력`을 누르면 같은 월 컨텍스트의 패널/시트가 열리고 닫힌다.
- [ ] 전월 스냅샷이 있는 월에서 입력 패널이 전월 항목과 금액으로 채워진다.
- [ ] 입력 패널에서 소유자별/자산유형별 그룹 전환과 그룹 선택이 표 목록에 반영된다.
- [ ] 입력 중 `임시 저장` 후 패널을 닫고 다시 열면 브라우저 임시저장본을 불러올 수 있다.
- [ ] 임시저장본을 삭제하면 같은 월 패널에서 저장 상태가 사라지고 `불러오기`가 비활성화된다.
- [ ] 예금/CMA/현금성 자산은 평가금액만 입력할 수 있고 저장 후 월별 현황 총액에 반영된다.
- [ ] 주식/ETF/금/코인 등 수량형 자산은 수량, 현재가, 환율, 원화 현재가 입력 후 평가금액이 계산되고 수정 가능하다.
- [ ] 전월에는 있었지만 이번 달 금액이 비어 있는 행은 저장 전에 경고/차단된다.
- [ ] 전량 정리한 항목은 0원으로 저장했을 때 `정리됨` 상태가 표시되고 월별 현황/추이에 0원으로 반영된다.
- [ ] 입력 패널 하단의 `자산 추가`로 기존 계좌/자산 조합을 추가하고 저장할 수 있다.
- [ ] `업로드` 후 `/asset/monthly`의 총자산, 전월 대비, 보유 목록 delta가 갱신되고 임시저장 상태가 제거된다.
- [ ] 모바일/데스크톱/다크 모드에서 입력 패널, 표, CTA, 상태 배지가 겹치지 않는다.

## 자산 포트폴리오 (`/asset/portfolio`)

- [ ] 자산군/리스크 기준 포트폴리오 차트가 표시된다.
- [ ] 포트폴리오 상세 패널이 선택한 항목에 맞게 갱신된다.
- [ ] 데이터가 없는 상태에서 차트 영역이 깨지지 않는다.

## 자산 추이 (`/asset/trend`)

- [ ] 기본 최근 6개월 범위로 총자산 추이 차트가 로드된다.
- [ ] 기간 선택 변경 시 추이 데이터가 다시 로드된다.
- [ ] 월별 증감, 상위 상승/하락 자산, 구성원별 요약이 표시된다.
- [ ] 추이 데이터가 없는 범위에서 빈 상태가 표시된다.

## 자산 거래 (`/asset/transactions`)

- [ ] 선택 월의 매수/매도/배당/이체 거래가 표시된다.
- [ ] 거래 입력 행에서 계좌, 종목, 유형, 날짜, 수량, 가격을 입력해 저장할 수 있다.
- [ ] 저장 후 거래 목록이 갱신되고 보유 수량/평균단가가 기대대로 반영된다.
- [ ] 삭제 후 거래 목록과 보유 수량/평균단가가 재계산된다.
- [ ] 필수 입력 누락 또는 API 실패 시 오류 상태가 표시된다.
