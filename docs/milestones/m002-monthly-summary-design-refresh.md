# M002. 월별 요약 디자인 개선

## 설명

`/summary/monthly`는 DB 기반 월별 수입/지출, 잔액, 카테고리 breakdown을 이미 표시하지만 기존 배치는 차트가 먼저 보이고 월간 현금흐름의 핵심 지표가 보조 정보처럼 보였습니다. 이 마일스톤은 API, Prisma schema, service 집계 로직, 타입 구조를 변경하지 않고 기존 월별 요약 데이터를 더 명확한 KPI, 비교 차트, 카테고리 분석 카드, 빈 상태로 재구성합니다.

완료 후 사용자는 선택 월의 수입, 지출, 잔액, 카테고리 비중을 한 화면에서 자연스럽게 이해할 수 있어야 합니다.

## Goals

- [x] 월별 요약 상단에서 총수입, 총지출, 잔액의 우선순위가 명확하게 보인다
- [x] 수입/지출 비교와 카테고리 분석 카드가 데스크톱/모바일에서 자연스럽게 배치된다
- [x] 거래가 없는 월과 카테고리 데이터가 없는 상태가 깨진 차트 대신 빈 상태로 표시된다
- [x] 월 이동, 상세 보기, 거래 추가, 카테고리 선택 동작이 기존과 동일하게 유지된다
- [x] 다크 모드와 작은 화면에서 텍스트, 버튼, 차트 라벨이 겹치지 않는다

## Goal 상세

### KPI 우선순위 개선

잔액을 핵심 지표로 두고 총수입/총지출을 보조 지표로 배치합니다. 금액이 길어져도 카드 안에서 깨지지 않도록 `min-w-0`, `break-words`, `overflow-wrap:anywhere`를 사용합니다.

### 분석 카드 레이아웃 정리

`CategoryBreakdownChart`, `IncomeExpenseChart`, `SummaryCardGroup`만 재배치하고 새 API나 새 집계 데이터는 추가하지 않습니다. 상단 KPI 아래에 수입/지출 비교 카드와 카테고리 분석 카드를 배치합니다.

### 빈 상태 개선

거래가 없는 월에는 0원 KPI가 유지되고, 수입/지출 차트와 카테고리 차트는 빈 데이터로 렌더링하지 않고 안내형 빈 상태를 표시합니다.

### 기존 동작 보존

월 선택, 이전/다음 월 이동, 상세 보기, 거래 추가 링크, 카테고리 클릭 상세 패널 동작을 유지합니다. 상세 보기와 거래 추가 버튼은 기존 URL 쿼리 구조를 그대로 사용합니다.

### 반응형/다크 모드 검증

모바일/데스크톱/다크 모드에서 텍스트, 버튼, 차트 라벨, 카테고리 선택 상세 패널의 겹침과 대비를 수동 체크리스트로 확인합니다. 자동 검증 후 사용자가 브라우저에서 표시가 괜찮음을 확인했습니다.
