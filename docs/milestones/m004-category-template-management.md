# M004. 카테고리와 반복 템플릿 관리 완성

## 설명

카테고리와 반복 템플릿은 현재 조회 중심으로만 구현되어 있어, 사용자가 직접 만들고 고치고
지울 수 없습니다. 이 마일스톤은 카테고리·반복 템플릿의 생성/수정/삭제 API와 관리 UI를
완성하고, 템플릿을 빠른 거래 생성과 연결하는 것을 목표로 합니다. 완료 후에는 가계부
분류 체계와 반복 입력 흐름을 코드 변경 없이 사용자가 직접 운영할 수 있습니다.

## Goals

- [ ] 카테고리를 생성/수정/삭제할 수 있다
- [ ] 카테고리 관리 UI에서 계층형 카테고리를 관리할 수 있다
- [ ] 반복 템플릿을 생성/수정/삭제할 수 있다
- [ ] 템플릿 목록/관리 UI와 빠른 거래 생성 UX가 연결되어 있다

## Goal 상세

### 카테고리 생성/수정/삭제

현재 `GET /api/categories`(flat/grouped) 조회만 있으므로 생성/수정/삭제 API를 추가하고,
계층형 카테고리 모델의 제약(부모-자식, 사용 중 카테고리 삭제 정책)을 정의합니다.

### 계층형 카테고리 관리 UI

카테고리 트리를 보고 추가·이동·이름 변경·삭제할 수 있는 관리 화면을 제공합니다.

### 반복 템플릿 생성/수정/삭제

현재 `GET /api/templates` 조회만 있으므로 템플릿 CRUD API와 검증을 추가합니다.

### 템플릿 → 빠른 거래 생성 UX

템플릿 목록/관리 UI를 제공하고, "템플릿 클릭 즉시 거래 생성" 흐름을 거래 입력 패널과
연결합니다.
