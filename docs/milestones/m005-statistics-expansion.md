# M005. 통계 기능 확장

## 설명

현재 통계 서비스는 월별/카테고리 일부만 제공하고 연간 통계 전용 화면이 없습니다. 이
마일스톤은 연간 집계와 추이 분석을 실제 데이터로 보여주는 통계 화면을 확장하는 것을
목표로 합니다. 완료 후에는 월 단위를 넘어선 기간 흐름과 카테고리별 분석을 확인할 수
있습니다.

## Goals

- [ ] 연간 통계 화면이 실제 연간 집계 데이터를 표시한다
- [ ] 월별 수입/지출 추이 차트를 확인할 수 있다
- [ ] 카테고리별 연간/기간별 분석을 확인할 수 있다
- [ ] 기간 선택, 증감률, CSV export 필요 여부가 결정되어 있다

## Goal 상세

### 연간 통계 집계 화면

연간 수입/지출/잔액 집계를 계산하는 service/API와 전용 라우트·화면을 정의·구현합니다.

### 월별 수입/지출 추이 차트

연간 범위에서 월별 수입/지출 추이를 Nivo line/bar 차트로 표시합니다.

### 카테고리별 연간/기간별 분석

카테고리 breakdown을 연간 또는 임의 기간 단위로 분석하는 흐름을 제공합니다.

### 기간 선택·증감률·export 정책

사용자 기간 선택 UX, 전기 대비 증감률 표시, CSV export 필요 여부와 범위를 결정합니다.
