# M007. 문서 동기화

## 설명

README가 create-next-app 기본 내용에 가깝고 `ROADMAP.md`는 초기 계획 기준이라 현재 구현
상태와 차이가 있습니다. 이 마일스톤은 사용자/개발자용 진입 문서를 현재 WeFolio 기준으로
정리하고, 기능 구현 시 문서가 함께 갱신되는 흐름을 확립하는 것을 목표로 합니다.

## Goals

- [ ] README가 WeFolio 기준 소개/실행/DB 초기화 문서로 정리되어 있다
- [ ] `ROADMAP.md`가 현재 구현 상태 기준으로 갱신되거나 archive 처리되어 있다
- [ ] 기능 구현 시 상태 표, 마일스톤 현황, 상세 문서가 함께 갱신된다

## Goal 상세

### README 정리

README를 WeFolio 소개·실행 방법·DB 초기화 안내로 교체합니다. 실행/초기화 절차는
`docs/build-and-dependencies.md`와 일치시킵니다.

### ROADMAP 갱신/archive

`ROADMAP.md`를 현재 구현 상태 기준으로 갱신하거나, 초기 계획 기록으로 archive 처리하고
실제 상태 기준은 `docs/project-status.md`임을 명확히 합니다.

### 문서 동반 갱신 흐름

기능 구현·제약 해소 시 `docs/project-status.md` 상태 표·마일스톤 현황과 해당 상세 문서가
함께 갱신되는 운영 흐름이 `docs/doc-management.md` 규칙대로 지켜지는지 점검합니다.
