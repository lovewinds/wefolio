# 인사이트 화면 & 지표 정의

기존 불만("투자 현황·수익 상태를 보여줄 구조가 부족")을 해소하는 화면들이다.
**모든 지표는 월별 스냅샷 필드만으로 계산된다** (별도 저장 없음).

## 공통 기호

월 `m`의 스냅샷에서:

```
원금(principal)     P(m)  = Σ over holdings  quantity × avgCostKRW
투자평가액(value)    V(m)  = Σ over holdings  quantity × currentPriceKRW
현금(cash)          C(m)  = Σ over accounts  cashBalanceKRW
총자산(net worth)    N(m)  = C(m) + V(m)
평가손익(unrealized) G(m)  = V(m) − P(m)
```

모든 합계는 구성원·기관·자산군·위험구분 등 임의 차원으로 필터·그룹할 수 있다.

---

## 1. 투자 수익 현황 (FR-C1)

종목별·전체의 투자 성과.

| 지표 | 식 |
|------|-----|
| 원금 | `quantity × avgCostKRW` |
| 평가액 | `quantity × currentPriceKRW` |
| 수익 | `평가액 − 원금` |
| 수익률 | `수익 / 원금` (원금 0 → "—" 표시) |

- **화면**: 종목 테이블(원금·평가액·수익·수익률, 손익 색상) + 상단 전체 요약 카드.
- value형(현금성) 종목은 수익이 0이므로 기본적으로 투자 성과 표에서 제외하거나 별도 표기.

## 2. 현금 vs 투자 비중 (FR-C2)

총자산이 어떻게 배분돼 있나.

| 지표 | 식 |
|------|-----|
| 현금 비중 | `C(m) / N(m)` |
| 투자 비중 | `V(m) / N(m)` |
| 위험자산 비중 | `Σ(riskLevel=위험자산 평가액) / N(m)` |
| 안전자산 비중 | 현금 + `riskLevel=안전자산` 평가액 비율 |

- **화면**: 도넛 차트(현금/투자) + 위험/안전 분포 바. (Nivo pie / bar)

## 3. 자산 추이 (FR-C3)

시간에 따른 변화.

- 월별 시계열로 `N(m)`, `V(m)`, `C(m)` 를 함께 그린다.
- 선택적으로 `P(m)`(원금)과 `V(m)`(평가액)을 겹쳐 그려 수익 갭을 시각화.
- **화면**: 라인 차트, 기본 최근 6개월·사용자 기간 선택. (Nivo line)

## 4. 구성별 분해 (FR-C4)

특정 월의 포트폴리오 구성.

- **구성원별** / **기관별** / **자산군별**(주식·채권·예금·금·코인) 평가액(또는 총자산) 비중.
- **화면**: 차원 토글이 있는 파이/스택 바. (Nivo pie / bar)

## 5. ★ 자산 변화 분해 (FR-C5)

월별 스냅샷만으로 **총자산이 어디에서 어떻게 변했는지** 를 보여주는 핵심 인사이트.
거래 기록 없이 실현손익과 외부 저축액을 확정 귀속하지 않는다. 대신 확정 가능한
상태 변화와 스냅샷 패턴 기반 추정 인사이트를 분리해 보여준다.

기간 `m-1 → m`의 총자산 변화는 다음 항등식으로 분해한다:

```
ΔN = N(m) − N(m-1)
   = ΔC + ΔV

  ΔC = C(m) − C(m-1)        // 현금 변화
  ΔV = V(m) − V(m-1)        // 투자 평가액 변화
  ΔV = ΔP + ΔG
  ΔP = P(m) − P(m-1)        // 보유원금 변화
  ΔG = G(m) − G(m-1)        // 미실현손익 변화
```

이를 사용자 언어로 표시한다:

| 표시 항목 | 식 | 의미 |
|-----------|-----|------|
| **총자산 변화** | `ΔN` | 이번 달 총자산의 순증감 |
| **현금 잔고 변화** | `ΔC` | 월말 현금 잔고의 변화 |
| **투자 평가액 변화** | `ΔV` | 월말 투자 평가액의 변화 |
| **보유원금 변화** | `ΔP` | 현재 보유 중인 자산의 원금 변화 |
| **미실현손익 변화** | `ΔG` | 현재 보유 중인 자산의 평가손익 잔액 변화 |

- **화면**: 워터폴/스택 바 — 시작 총자산 → (+현금 변화) → (+투자 평가액 변화) → 끝 총자산. 투자 평가액 변화는 하위로 `ΔP + ΔG`를 함께 표시한다. (Nivo bar)

### 해석 주의 (중요)

- `ΔG`는 **투자수익 전체가 아니라 미실현손익 잔액의 변화**다. 매도해 현금화하면 과거의
  미실현손익이 현금으로 옮겨가며 `ΔG`가 줄 수 있으므로, 이를 손실로 단정하지 않는다.
- 거래 기록이 없으므로 실현손익, 외부 저축액, 매수/매도 금액은 확정 계산하지 않는다.
- 현금↔투자 이동, 현금화, 보유 수량 변화는 스냅샷 패턴 기반 **추정 인사이트**로 표시한다.
- 평균단가를 사용자가 보정하면 `P`가 점프해 특정 월의 `ΔP`/`ΔG` 분해가 왜곡될 수 있다.
  → 보정월은 화면에 표식을 남긴다(분해 신뢰도 주석).

### 스냅샷 패턴 기반 추정 인사이트

| 감지 항목 | 조건 | 표시 원칙 |
|-----------|------|-----------|
| **현금 → 투자 이동 추정** | `ΔC < 0`, `ΔV > 0`, `abs(ΔC + ΔV)`가 작음 | "현금에서 투자로 이동한 변화가 감지됩니다" |
| **투자 → 현금화 추정** | `ΔC > 0`, `ΔV < 0`, `abs(ΔC + ΔV)`가 작음 | "투자자산 일부를 현금화한 변화가 감지됩니다" |
| **보유 수량 증가** | 동일 보유의 수량 증가 | "추가 매수 또는 이체 입고 가능성" |
| **보유 수량 감소** | 동일 보유의 수량 감소 | "일부 매도 또는 이체 출고 가능성" |
| **신규 보유** | 전월 없음/0 → 이번 달 수량 > 0 | "신규 보유" |
| **정리** | 전월 수량 > 0 → 이번 달 없음/0 | "정리" |

추정 인사이트는 확정 거래가 아니므로 "매수했다", "매도했다"처럼 단정하지 않는다.
