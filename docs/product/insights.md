# 인사이트 화면 & 지표 정의

기존 불만("투자 현황·수익 상태를 보여줄 구조가 부족")을 해소하는 화면들이다.
**모든 지표는 월별 스냅샷 필드만으로 계산된다** (별도 저장 없음).

## 공통 기호

월 `m`의 스냅샷에서. 종목형 보유 `h`의 수량 `q`, 현재가(원화) `p`:

```
원금(principal)     P(m)  = Σ over 종목형 holdings  q × avgCost
투자평가액(value)    V(m)  = Σ over 종목형 holdings  q × p
현금(cash)          C(m)  = Σ cashBalanceKRW  +  Σ value형(현금성) 종목 평가액
총자산(net worth)    N(m)  = C(m) + V(m)
평가손익(unrealized) G(m)  = V(m) − P(m)
```

- `avgCost`(평균단가)는 매번 입력하지 않아도 스냅샷의 수량 변화로 **자동 파생**한다(§1 평균단가 자동 파생). 덕분에 `P`·`G`가 의미를 가진다.
- **value형**(현금성: 예금·청약·MMF·포인트 등 — 수량·가격 없이 평가액 한 값만 입력)은 **현금처럼 취급**한다. `C`에 포함되고, 변화 분해(FR-C5)에서 시장 손익이 아니라 현금/외부 순유입으로 귀속된다.
- 모든 합계는 구성원·기관·자산군·위험구분 등 임의 차원으로 필터·그룹할 수 있다.

## 1. 투자 수익 현황 (FR-C1)

종목별·전체의 투자 성과.

| 지표 | 식 |
|------|-----|
| 원금 | `quantity × avgCostKRW` |
| 평가액 | `quantity × currentPriceKRW` |
| 평가손익 | `평가액 − 원금` (미실현) |
| 수익률 | `평가손익 / 원금` (원금 0 → "—" 표시) |

- **화면**: 상단 2단 — ① 와이드 히어로(좌측 라벨 · 우측 기준일(미실현), 미실현 평가손익·수익률 핵심 수치 좌측 정렬·상하 중앙, 막대 바로 위에 원금·평가액 한 줄, 하단 원금/손익 분할 막대) ② 손익 종목 카드(이익 N·손실 M + 이익/손실 상위 종목 간략 목록: 종목·계좌·수익률). 그 아래 **차원별 성과 비교 카드**(구성원/자산군/기관/연금·일반 토글 → 그룹별 원금·평가액·비중·평가손익·수익률+막대, 현금형 제외) + 종목 테이블(원금·평가액·비중·평가손익·수익률, 손익 색상, 구성원·위험구분·자산군·기관·검색 필터). 금액 손익 용어는 `평가손익`으로 통일(공통기호 `G`와 정합).
- value형(현금성) 종목은 평가손익이 0이므로 기본적으로 투자 성과 표에서 제외하거나 별도 표기.

### 평균단가 자동 파생

엑셀·기본 입력엔 평균단가가 없어 시드는 `avgCost = 현재가`(수익 0)로 시작한다. 이후 스냅샷의
**수량 변화로 평균단가를 자동 파생**해 `P`·`G`(원금·미실현손익)가 실제 의미를 갖게 한다.

| 상황 | 규칙 |
|------|------|
| 신규 보유 | `avg = p_curr` (이번 달 현재가) |
| 수량 증가 `Δq > 0` (추가 매수 추정) | `avg_new = (q_prev·avg_prev + Δq·p_curr) / q_curr` (가중평균) |
| 수량 감소/동일 (매도·보유) | `avg` 유지 (매도는 평균단가를 바꾸지 않음) |

- 파생값은 입력 시 **prefill**되어 스냅샷(`avgCostKRW`)에 저장된다(스냅샷이 SSOT — 원금·수익 등 다른 파생값은 저장하지 않음). 사용자가 평균단가를 직접 입력하면 그 값이 우선하고 **보정월 표식**을 남긴다.
- **실현손익 추정**: 매도 시 `|Δq| × (p_curr − avg_prev)` (월말가 근사, 추정 표현).
- **시작점 한계**: 과거 체결가 기록이 없어 최초 스냅샷의 현재가를 원가 시작점으로 본다(근사). 이후부터 파생이 누적된다.
- **수량 증가 = 매수 가정**: 무상증자·분할·이체 입고도 수량 증가로 보여 매수로 오인할 수 있다(추정). 다르면 사용자가 평균단가를 직접 보정한다.
- **적용**: 저장 시 서버(`saveMonthlyInput`)가 직전 스냅샷을 조회해 권위적으로 파생한다(스냅샷이 SSOT). 입력 화면은 수량/현재가 변경에 맞춰 같은 규칙으로 평균단가 칸을 prefill하고, 사용자가 직접 고치면 보정값(`avgCostManual`)으로 보내 우선한다. value형(현금성)은 파생 대상이 아니다. FR-C5(저축/시장) 분해는 평균단가와 무관하므로 영향받지 않는다.
- **구현 현황**: 파생·보정·**로드/시드 백필**(보유별 시간순 재파생, `prisma/seed/backfill-avg-cost.ts` — 로드 끝에서 자동 호출, 수동 실행은 `pnpm db:backfill-avgcost`) 구현됨. value형은 백필 제외. **보정월 표식·실현손익 표시는 후속.**

## 2. 현금 vs 투자 비중 (FR-C2)

총자산이 어떻게 배분돼 있나.

| 지표 | 식 |
|------|-----|
| 현금 비중 | `C(m) / N(m)` |
| 투자 비중 | `V(m) / N(m)` |
| 위험자산 비중 | `Σ(riskLevel=위험자산 평가액) / N(m)` |
| 안전자산 비중 | 현금 + `riskLevel=안전자산` 평가액 비율 |

- **화면**: 도넛 차트(현금/투자) + 위험/안전 분포 바. (Nivo pie / bar)

## 3. 자산 추이 (FR-C3)

시간에 따른 변화.

- 월별 시계열로 `N(m)`, `V(m)`, `C(m)` 를 함께 그린다.
- 선택적으로 `P(m)`(원금)과 `V(m)`(평가액)을 겹쳐 그려 수익 갭을 시각화.
- **화면**: 라인 차트, 기본 최근 6개월·사용자 기간 선택. (Nivo line)

## 4. 구성별 분해 (FR-C4)

특정 월의 포트폴리오 구성.

- **구성원별** / **기관별** / **자산군별**(주식·채권·예금·금·코인) 평가액(또는 총자산) 비중.
- **화면**: 차원 토글이 있는 파이/스택 바. (Nivo pie / bar)

## 5. ★ 자산 변화 분해 (FR-C5)

월별 스냅샷만으로 **총자산이 어디에서 어떻게 변했는지**를 보여주는 핵심 인사이트.
거래 기록이 없어도, 연속한 두 스냅샷의 (수량 `q`, 가격 `p`) 쌍만으로 평가액 변화를
**가격 효과**와 **매매 효과**로 정확히(항등식) 나누고, 이를 현금 변화와 묶어
**"외부 순유입(저축·납입) vs 시장 손익"** 으로 보여준다. (원가 데이터가 없어도 성립한다.)

### 종목별 분해

종목형 보유 `h`의 평가액 변화 `ΔV_h = q_curr·p_curr − q_prev·p_prev` 를 두 효과로 나눈다:

```
가격 효과(market) = q_prev × (p_curr − p_prev)   // 직전부터 들고 있던 수량의 가격 변동분
매매 효과(flow)   = (q_curr − q_prev) × p_curr   // 수량 변화분을 월말가로 평가(순매수/매도 추정액)

ΔV_h = 가격 효과 + 매매 효과                       // 교차항 Δq·Δp 는 매매 효과에 귀속
```

- **신규 보유**(전월 없음/0): 가격 효과 = 0, 매매 효과 = `q_curr × p_curr`.
- **정리**(이번 달 없음/0): 가격 효과 = 0, 매매 효과 = `−q_prev × p_prev`(마지막 알려진 가격).
- 가격 효과는 **직전 보유 수량(`q_prev`)** 에만 적용한다(월중 새로 산 수량엔 가격 이익을 귀속하지 않음 — 보수적).

### 전체 분해

```
ΔN = N(m) − N(m-1) = ΔC + ΔV
   = [ ΔC + Σ_h 매매 효과 ]  +  [ Σ_h 가격 효과 ]
   =   외부 순유입(저축·납입)   +     시장 손익
```

| 표시 항목 | 식 | 의미 |
|-----------|-----|------|
| **총자산 변화** | `ΔN` | 이번 달 총자산의 순증감 |
| **외부 순유입(저축·납입)** | `ΔC + Σ 매매 효과` | 외부에서 들어온/나간 순액. 현금↔투자 내부 이동은 상쇄되어 **실질 저축액**만 남음 |
| **시장 손익** | `Σ 가격 효과` | 보유 자산의 가격 변동으로 생긴 이번 달 손익 |
| (하위) **종목별 기여** | 종목별 가격/매매 효과 | 어떤 종목이 시장 손익·순유입에 얼마 기여했나 |

> 왜 "외부 순유입 = 저축"인가: 현금으로 투자를 사면 `ΔC<0` 와 `매매 효과>0` 가 상쇄되고, 팔면 반대로
> 상쇄된다. 내부 이동이 지워지고 남는 것은 **외부에서 새로 들어온 돈(수입−지출−외부 이체)** 뿐이다.

### 단순 케이스 (사용자 기준)

| 케이스 | 스냅샷 변화 | 분해 결과 |
|--------|-------------|-----------|
| 가격만 상승 | 현금 그대로, 수량 동일, 가격 ↑ | 매매 효과 0 → **시장 손익 +**, 순유입 0 |
| 추가 매수 | 현금 ↓, 수량 ↑ | `ΔC<0`+`매매 효과>0` 상쇄 → **순유입 ≈ 0**(내부 이동) |
| 매도(현금화) | 현금 ↑, 수량 ↓ | `ΔC>0`+`매매 효과<0` 상쇄 → **순유입 ≈ 0**(내부 이동) |
| 월급 저축 | 현금 ↑, 수량 동일 | 매매 효과 0 → **순유입 +**(저축), 시장 손익 0 |

> 수치 예시: 직전월 `A 10주@100`(현금 50), 이번 달 `A 12주@110`(현금 28).
> `ΔV = 12·110 − 10·100 = 320`, 가격 효과 `= 10·(110−100) = 100`, 매매 효과 `= 2·110 = 220`, `ΔC = −22`.
> **시장 손익 = 100**, **외부 순유입 = −22 + 220 = 198**(현금 22 + 외부 유입으로 2주 매수), `ΔN = 298` ✓.

- **화면**: 히어로 2카드(외부 순유입 vs 시장 손익) + 워터폴(시작 `N` → +순유입 → +시장 손익 → 끝 `N`, 종목별 기여 드릴다운). 디자인 프로토타입 `design/views-insight.jsx`의 저축/시장 분해와 일치. (Nivo bar)

### 해석 주의 (중요)

- **시장 손익은 직전 보유분의 가격 변동만** 확정한다. 월중에 산 수량의 가격 변동, 배당·이자·수수료는
  체결 시점 가격을 모르므로 시장 손익으로 확정하지 않고 **외부 순유입에 섞인다**. 스냅샷이 잦을수록 오차가 준다.
- **매매 효과는 월말가 근사**다(중간 거래 시점·체결가 미상). "정확한 매수/매도 금액"이 아니라 추정 규모다.
- 결측 월(스냅샷 건너뜀)은 다음 스냅샷까지 한 기간으로 묶여 분해된다.
- FR-C5의 순유입/시장 분해는 평균단가와 **무관하게** 성립한다. 다만 `P`·`G`(원금·미실현손익 잔액, FR-C1)는
  평균단가에 의존하므로, 사용자가 평균단가를 덮어쓰면 그 달 `P`·`G`가 점프할 수 있어 보정월 표식을 남긴다.

### 스냅샷 패턴 기반 추정 인사이트

| 감지 항목 | 조건 | 표시 원칙 |
|-----------|------|-----------|
| **현금 → 투자 이동 추정** | `ΔC < 0`, `ΔV > 0`, 순유입 ≈ 0 | "현금에서 투자로 이동한 변화가 감지됩니다" |
| **투자 → 현금화 추정** | `ΔC > 0`, `ΔV < 0`, 순유입 ≈ 0 | "투자자산 일부를 현금화한 변화가 감지됩니다" |
| **보유 수량 증가** | 동일 보유의 수량 증가 | "추가 매수 또는 이체 입고 가능성(약 N만원 규모)" |
| **보유 수량 감소** | 동일 보유의 수량 감소 | "일부 매도 또는 이체 출고 가능성(약 N만원 규모)" |
| **신규 보유** | 전월 없음/0 → 이번 달 수량 > 0 | "신규 보유" |
| **정리** | 전월 수량 > 0 → 이번 달 없음/0 | "정리" |

"약 N만원 규모"는 매매 효과 금액(`Δq × p_curr`)이다. 추정 인사이트는 확정 거래가 아니므로
"매수했다", "매도했다"처럼 단정하지 않는다.

## 6. 확장 인사이트 (후속 — 정식 스펙화는 추후)

위 분해에서 파생 가능한 추가 인사이트. 이번 범위에선 정의만 남기고 화면·구현은 후속에서 다룬다.

- **누적 순투입 vs 평가액 갭** (FR-C3 확장): 외부 순유입 누적선과 총자산선을 겹쳐 "넣은 돈 대비 얼마나 불었나"를 본다.
- **기간 수익률(TWR 근사 / 간이 Dietz)**: 월별 시장 손익 ÷ 평가액으로 외부 현금흐름 영향을 제거한 수익률.
- **외화 가격/환율 분리**: 가격 효과를 `priceOriginal`(순가격 등락)과 `exchangeRate`(환율 등락) 변동분으로 더 분리.
- **행동 패턴**: 저축 꾸준함(월별 순유입 추이), 시장 vs 저축 기여 비중 추이, 비중 드리프트(FR-C4 결합).
