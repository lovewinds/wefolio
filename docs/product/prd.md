# PRD — 제품 요구사항

## 1. 제품 정의

WeFolio는 **가족 단위의 자산 포트폴리오와 가계부**를 관리하는 웹 서비스다.
여러 가족 구성원(예: 지완, 지아)의 계좌·자산을 한곳에 모아,
매월 현황을 기록하고 **총자산·현금·투자 평가액의 변화와 현재 보유 자산의 평가 상태**를
시각적으로 이해하도록 돕는다.

## 2. 대상 사용자

- **주 사용자**: 가계 재무를 관리하는 가족 구성원(부부 등). 다수의 은행·증권 계좌를 보유.
- **사용 빈도**: 자산은 **월말 정기 기록**을 기본으로 하되 필요 시 주 단위 등 더 자주 기록 가능, 가계부는 수시 기록.
- **데이터 입력 주체**: 시세 자동 연동 없이 **사용자가 직접 입력**한다.

## 3. 목표 (Goals)

1. 현금 잔고와 투자 종목을 **명확히 분리**해 관리한다.
2. 종목별·전체 **투자 수익과 수익률**을 보여준다.
3. 총자산 변화를 **외부 순유입(저축·납입)** 과 **시장 손익**으로 분해해, "저축으로 늘었나
   시장으로 늘었나"를 보여준다. (두 스냅샷의 수량·가격에서 가격 효과/매매 효과로 산출)
4. 기존의 이중 추적 복잡성을 제거해 **월별 스냅샷 하나로** 모든 것을 운영한다.

### 비목표 (Non-Goals)

- 외부 시세/환율 API 연동 (전부 수동 입력)
- 매수/매도 거래 단위 기록 및 자동 평균단가 재계산
- 거래 기록이 필요한 실현손익·외부 저축액의 확정 귀속
- 리밸런싱 목표·권장 비중 등 정책성 기능
- 가계부와 자산 관리의 통합 분석 (두 도메인은 독립)

## 4. 범위 (Scope)

### In Scope

| 영역 | 내용 |
|------|------|
| 자산 — 기준 데이터 | 구성원·기관·계좌·종목(AssetMaster) **CRUD** |
| 자산 — 월별 기록 | 계좌 현금 잔고 + 보유 종목(수량·평균단가·현재가) 월별 입력 |
| 자산 — 인사이트 | 수익 현황, 현금/투자 비중, 자산 추이, 구성별 분해, 자산 증가 분해 |
| 가계부 (기본) | 수입/지출 거래 CRUD, 계층형 카테고리, 고정 지출 템플릿, 월별 요약 |

### Out of Scope

위 [비목표](#비목표-non-goals) 참조.

## 5. 기능 요구사항

### FR-A 자산 기준 데이터
- **FR-A1** 구성원(Member)을 등록/수정/비활성화한다. (이름, 표시 색상)
- **FR-A2** 기관(Institution)을 등록/수정한다. (이름, 유형: 은행/증권)
- **FR-A3** 계좌(Account)를 등록/수정한다. (구성원·기관·계좌유형·통화)
- **FR-A4** 종목(AssetMaster)을 등록/수정한다. (이름·자산군·세부분류·위험구분·통화)
- 기존의 "수정/삭제 불가" 제약을 해소한다 — 모든 기준 데이터는 편집 가능해야 한다.

### FR-B 자산 월별 기록
- **FR-B1** 월을 선택하면 **전월 스냅샷이 자동 복사**되어 입력 폼이 채워진다.
- **FR-B2** 계좌별 **현금 잔고**(원화)를 한 줄로 입력한다.
- **FR-B3** 보유 종목은 **수량·평균단가·현재가**를 입력한다. (현금형 종목은 평가액 한 값만)
- **FR-B4** 외화 종목은 **통화·환율**을 입력하면 원화 환산값을 저장한다.
- **FR-B5** 한 달의 스냅샷은 부분 누락 없이 저장된다. (복사 기반이므로 누락이 구조적으로 발생하지 않음)

### FR-C 인사이트 (자세한 정의식은 [insights.md](./insights.md))
- **FR-C1** 투자 수익 현황: 종목별/전체 원금·평가액·수익·수익률. 평균단가는 스냅샷 수량 변화로 자동 파생(사용자 보정 가능).
- **FR-C2** 현금 vs 투자 비중 + 위험/안전 자산 분포.
- **FR-C3** 자산 추이: 월별 총자산·투자평가액·현금 시계열.
- **FR-C4** 구성별 분해: 구성원/기관/자산군 파이.
- **FR-C5** 자산 변화 분해: `Δ총자산 = 외부 순유입(저축·납입) + 시장 손익` — 두 스냅샷의 (수량·가격)에서
  종목별 가격 효과/매매 효과로 분해(원가 불필요). 현금화·보유 수량 변화는 스냅샷 패턴 기반 추정 인사이트로 표시한다.

### FR-D 가계부 (기본)
- **FR-D1** 수입/지출 거래를 등록/수정/삭제한다. (금액·일자·카테고리·결제수단·구성원·메모)
- **FR-D2** 계층형 카테고리(대분류/소분류)를 관리한다.
- **FR-D3** 고정 지출/수입 템플릿으로 빠르게 거래를 생성한다.
- **FR-D4** 월별 수입·지출 요약과 카테고리별 합계를 본다.

## 6. 비기능 요구사항

- **NFR-1 간결성**: 자산 도메인의 표준 운영 흐름은 거래 기록에 의존하지 않는다(스냅샷 SSOT). 거래 기록은 비권위 보조로만 유지한다. ([asset-management.md](./asset-management.md) ADR 참조)
- **NFR-2 정합성**: 평가액·원금·미실현손익은 항상 스냅샷 필드에서 파생되며 별도 저장하지 않는다.
- **NFR-3 무손실 이관**: 기존 엑셀 시드 데이터를 새 모델에 손실 없이 적재할 수 있다. ([data-model.md](./data-model.md) 매핑표)
- **NFR-4 반응형**: 모바일/데스크톱, 라이트/다크 모드를 지원한다.
- **NFR-5 LNB 접기**: 좌측 LNB는 접어 아이콘 전용 모드(폭 248px↔72px)로 전환할 수 있다. 토글은 상단 브랜드 영역에 둔다. 접힘 상태에서는 메뉴 라벨을 숨기고 아이콘만 표시하며, 아이콘 호버 시 라벨 툴팁을 노출한다. 그룹 라벨(`메뉴`/`설정`)은 숨기는 대신 그룹 사이에 구분선을 둔다. 자산 하위 항목은 아이콘을 가지며, 펼침 시 아이콘+라벨로, 접힘 시 자산 페이지에 있을 때 자산 아이콘 아래에 아이콘만 노출한다. 접힘/펼침 상태는 localStorage에 저장해 재방문 후에도 유지한다.

## 7. 완료 기준 (Definition of Done)

1. 모든 인사이트 화면(FR-C)이 **월별 스냅샷 데이터만으로** 계산되어 렌더링된다.
2. 기준 데이터(FR-A) 전 항목이 UI에서 생성·수정 가능하다.
3. 스냅샷 입력(FR-B)이 직전 스냅샷 복사 → 수정 → 저장 흐름으로 동작한다(월말 기본, 주 단위 등 임의 일자 허용). 거래 기록은 비권위 보조이며 스냅샷 값을 자동으로 덮어쓰지 않는다.
4. 기존 엑셀 시드(`prisma/seed/`)가 새 스키마로 무손실 적재된다.
